spsc queue

a bounded, lock-free single-producer / single-consumer ring queue in c++20. one writer, one reader, no mutex, no allocation on the hot path.

c++20 header-only lock-free no hot-path alloc github ↗

what it is

a fixed-capacity ring buffer shared by exactly two threads: one that only pushes and one that only pops. that single constraint is what buys everything else. with one writer and one reader there is nothing to arbitrate, so the whole structure comes down to two counters and a pair of acquire / release fences — no locks, no CAS loop, no retry.

it is built for trading-style hot paths: pay for everything once, up front, then run try_push / try_pop in a tight loop where every operation is a bounds check, a placement new, and one atomic increment. both calls are non-blocking and return false instead of waiting — full is a valid answer, and so is empty.

design notes

  • small buffer optimization. capacity at or below InlineCapacity lives in an inline std::byte array right inside the object, so a small queue is one contiguous chunk of memory with no indirection and good locality. go past the threshold and it takes a single heap allocation at construction — never again after that.
  • raw storage, explicit lifetimes. the buffer is untyped bytes, aligned with alignas(T). elements are constructed in place with placement new and destroyed by an explicit destructor call on pop. nothing is default-constructed just to be overwritten later, which matters when T is something like a std::function task.
  • no false sharing. head_ and tail_ are each alignas(64), so the consumer's counter and the producer's counter land on separate cache lines. without that padding the two threads would ping-pong the same line back and forth and the lock-free version would lose to the mutex it was meant to beat.
  • monotonic counters, modulo indexing. the counters only ever increase; occupancy is just tail - head and the slot is (counter % capacity_) * sizeof(T). that removes the classic ambiguity where a full ring and an empty ring look identical, without burning a slot to distinguish them.
  • minimal ordering. each side reads its own counter relaxed (nobody else writes it) and the other side's counter acquire. the increment that publishes the work is release. that pairing is exactly enough to guarantee the reader sees a fully constructed element before it sees the index that exposes it, and not one fence more.
  • push takes ownership late. try_push checks for room before it moves from its argument, so a failed push on a full queue leaves the caller's value intact and never touches shared storage.
  • move, don't copy. copy construction and copy assignment are deleted — copying a queue that another thread is writing into is not a meaningful operation. the move operations transfer the heap pointer and memcpy the inline bytes, and assume the source queue has been drained.

benching it

bench/bench_queue.cpp moves ten million uint64_t values from a producer thread to the main thread and times the round trip, three ways:

  • spsc::Queue — producer spins on try_push, consumer spins on try_pop. no locks, no per-op allocation.
  • std::queue + mutex — take the lock on every single push and pop.
  • std::queue + condvar — same, plus a condition variable the consumer waits on, so you pay a syscall whenever it actually sleeps.

each one runs twice to warm up before the timed pass, and main() prints elapsed seconds and millions of ops/sec side by side. numbers move around a lot between machines, so it is worth running yourself — make bench.

the poc

src/main.cpp wraps the queue in something closer to how you would actually deploy it. a QueuePool placement-news a worst-case Q_MAX queues into one aligned buffer and hands them out through acquire() / release() against a simple free list — so a thread gets a queue without ever hitting the allocator. release() calls reset(), which destroys whatever is still in flight and rewinds both counters.

the payload is a Task: an id plus a std::function holding some simulated cpu work and a 25% chance of a microsecond sleep to stand in for i/o. the main thread pops and executes while the producer is still filling, so the ring runs up against its capacity and both sides genuinely contend — which is the point. in a real system this is the shape of a dispatcher: hand each worker a queue, keep the hot loop lock-free, and never allocate to move work around.

the source

include/spsc/queue.hpp raw ↗ 
#pragma once

// SPSC, bounded, lock-free ring queue with small buffer optimization.
// capacity <= InlineCapacity -> inline storage, else one heap alloc up front

#include <atomic>
#include <cstddef>
#include <cstring>
#include <utility>

namespace spsc {
template <typename T, std::size_t InlineCapacity = 64>
class Queue {
	
	public:
		Queue(std::size_t capacity = InlineCapacity);
		~Queue();
		Queue(Queue&&);
		Queue& operator=(Queue&&);

		// delete copy and copy assignment constructors
		Queue(const Queue&) = delete;
		Queue& operator=(const Queue&) = delete;

		bool try_push(T value);
		bool try_pop(T& out);
		inline void reset() {
			std::size_t head = head_.load();
			std::size_t tail = tail_.load();
			std::byte* s = heap_ ? heap_ : inline_;
			for (std::size_t i = 0; i < (tail - head); i++) {
				std::size_t idx = ((head + i) % capacity_) * sizeof(T);
				reinterpret_cast<T*>(&s[idx])->~T();
			}
			head_.store(0);
			tail_.store(0);
		}

		std::size_t capacity() const { return capacity_; }
		bool is_inline() const { return heap_ == nullptr; }

	private:
		alignas(T) std::byte inline_[InlineCapacity * sizeof(T)];
		std::byte* heap_ = nullptr;
		std::size_t capacity_ = 0;

		alignas(64) std::atomic<std::size_t> head_{0};  // consumer
		alignas(64) std::atomic<std::size_t> tail_{0};  // producer
};

template <typename T, std::size_t InlineCapacity>
Queue<T, InlineCapacity>::Queue(std::size_t capacity) {
	// if capacity is greater than our threshold, use indirection
	// otherwise we benefit from locality
	if (capacity > InlineCapacity) {
		heap_ = new std::byte[capacity * sizeof(T)];
	}
	capacity_ = capacity;
}

template <typename T, std::size_t InlineCapacity>
Queue<T, InlineCapacity>::~Queue() {
	// load head and tail -- they let us check occupancy and 
	// index into our ring buffer
	std::size_t head = head_.load();
	std::size_t tail = tail_.load();
	std::byte *s = heap_ ? heap_ : inline_;

	for (std::size_t i = 0; i < (tail - head); i++) {
		std::size_t idx = ((head + i) % capacity_) * sizeof(T);
		reinterpret_cast<T*>(&s[idx])->~T();
	}
	delete[] heap_;
}

template <typename T, std::size_t InlineCapacity>
Queue<T, InlineCapacity>::Queue(Queue<T, InlineCapacity>&& value) {
	// move ctor assumes the queue has been reset().
	// move resources, memcpy inline raw bytes
	capacity_ = value.capacity_;
	heap_ = value.heap_;
	head_.store(value.head_.load());
	tail_.store(value.tail_.load());
	std::memcpy(inline_, value.inline_, sizeof(inline_));
	value.heap_ = nullptr;
}

template <typename T, std::size_t InlineCapacity>
Queue<T, InlineCapacity>& Queue<T, InlineCapacity>::operator=(Queue<T, InlineCapacity>&& value) {
	// move assignment assumes the queue is empty.
	// move resources, memcpy inline raw bytes to new value

	if (this == &value) return *this; // prevent self assignment

	capacity_ = value.capacity_;
	heap_ = value.heap_;
	head_.store(value.head_.load());
	tail_.store(value.tail_.load());
	std::memcpy(inline_, value.inline_, sizeof(inline_));
	value.heap_ = nullptr;
	return *this;
}

template <typename T, std::size_t InlineCapacity>
bool Queue<T, InlineCapacity>::try_push(T value) {
	// grab head and tail to determine occupancy
	std::size_t head = head_.load(std::memory_order_acquire);
	std::size_t tail = tail_.load(std::memory_order_relaxed);
	if ((tail - head) >= capacity_) {
		return false;
	}

	// grab offset to determine where to emplace new value
	std::byte *s = heap_ ? heap_ : inline_;
	std::size_t idx = (tail % capacity_) * sizeof(T);

	// construct T in place and increment producer
	new (&s[idx]) T(std::move(value));
	tail_.fetch_add(1, std::memory_order_release);

	return true;
}

template <typename T, std::size_t InlineCapacity>
bool Queue<T, InlineCapacity>::try_pop(T& out) {
	// grab head and tail to determine occupancy
	std::size_t head = head_.load(std::memory_order_relaxed);
	std::size_t tail = tail_.load(std::memory_order_acquire);
	if ((tail - head) == 0) {
		return false;
	}

	// grab consumer offset to determine which item to pop
	std::byte *s = heap_ ? heap_ : inline_;
	std::size_t idx = (head % capacity_) * sizeof(T);

	// cast T into rvalue for assignment, invoke dtor, increment consumer
	out = std::move(*reinterpret_cast<T*>(&s[idx]));
	reinterpret_cast<T*>(&s[idx])->~T();
	head_.fetch_add(1, std::memory_order_release);
	return true;
}
